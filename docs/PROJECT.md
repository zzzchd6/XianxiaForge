# 项目总览：指尖仙侠（XianxiaForge / Novel Studio）

> 本文档是 Agent 了解本项目的**第一入口**。读完本文档后，按顺序继续阅读 `docs/ARCHITECTURE.md` → `docs/DATA_MODEL.md` → `docs/API.md` → `docs/PROMPTS.md` → `docs/CONFIG.md` → `docs/TODO.md` 即可建立完整认知。

## 一句话定位

基于**诛仙小说结构化世界观数据库**的多 Agent 管线 AI 长篇小说创作工作台——以诛仙库为世界观知识源（RAG），通过"上下文编排 → AI写作 → 一致性审计 → 自动修订 → 入库"的生成管线，产出设定一致、可人工掌控的小说章节。

## 核心目标

- **解决什么问题**：多主线剧情割裂、设定遗忘（人设/境界/关系漂移）、金句审美不稳定、质量参差（AI味重/逻辑断链/钩子乏力）
- **最终产出**：可交互的小说创作工作台——作者在"会自己运行的世界"里导演故事，AI 是创作助手而非代笔工具（作者主权 + 确定性兜底）

## 技术栈（一句话说清）

- **前端**：React 19 + Vite 6 + TailwindCSS 3.4 + TanStack Query 5 + React Router 7（TypeScript）
- **后端**：Hono 4.6 + Drizzle ORM 0.36（TypeScript，Node.js 20+）
- **数据库**：PostgreSQL（≥15）+ pgvector（512 维向量），双库架构
- **AI 能力**：任意 OpenAI-compatible LLM（openai SDK 4.70，支持 Ollama 本地 / DeepSeek / OpenAI），22 个 Agent 文件 + RAG 混合检索
- **工程**：pnpm monorepo（`packages/server` + `packages/web` + `packages/shared`），一键启动

## 关键设计理念

- **作者主权**：AI 输出永远可预览、可确认、可回滚；生成结果不自动覆盖原文（版本制）
- **确定性兜底**：LLM 只做"生成/判断"，品阶约束、稀有度限制、禁用词扫描、互斥校验等一律由确定性规则把关（零 token、零误判）
- **best-effort 降级红线**：所有增强能力失败时静默降级为空，绝不阻断主流程
- **文档是真相来源**：本 `docs/` 目录 7 个文件是 Agent 工作的第一参考，代码实现以技术手册为准
