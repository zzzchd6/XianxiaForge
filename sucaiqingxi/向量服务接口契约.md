# 向量服务接口契约 · embedding_server

> **冻结契约**：本文件定义 `embedding_server.py` 对外暴露的 HTTP 接口。
> 二期 Novel Studio（Node/TS）侧的召回代码**只依赖本契约**，不依赖 Python 实现细节。
> 契约变更必须走三步法（评估→审核→实施），并同步升级本文档版本号。

**契约版本**：v1（2026-07）
**服务**：`embedding_server.py`（Flask / 生产用 `serve_embedding.py` + waitress）
**默认地址**：`http://127.0.0.1:8600`（`EMBEDDING_SERVER_HOST` / `EMBEDDING_SERVER_PORT` 可配）

---

## 0. 铁律（不可协商）

- 模型：`BAAI/bge-small-zh-v1.5`
- 维度：**512**（与 pgvector `VECTOR(512)`、6 张表入库向量、诛仙库同源）
- 归一化：**是**（输出单位向量，L2 范数 = 1；配合 pgvector cosine `<=>`）
- 查询向量**必须**经本服务生成，Node 侧**不得**另接其它 embedding 模型。

---

## 1. `GET /health`

健康检查 / 维度自证。

**请求**：无 body。

**响应 200**：
```json
{ "status": "ok", "model": "BAAI/bge-small-zh-v1.5", "dim": 512 }
```

**用途**：二期启动自检、探活；`dim` 必须等于 `512`，否则视为环境错误，禁止上线召回。

---

## 2. `POST /embed`（推荐，Node 直连）

把一批文本转为 512 维归一化向量。

**请求头**：`Content-Type: application/json`

**请求体**：
```json
{ "texts": ["文本1", "文本2"] }
```
- `texts`：非空数组，或单个字符串（服务端自动包成数组）。
- 空串会被替换为单空格，不会报错。

**响应 200**：
```json
{ "embeddings": [[/* 512 个 float */], [/* 512 个 float */]], "dim": 512 }
```
- `embeddings` 与 `texts` **等长、同序**。
- 每个向量长度 = `512`，L2 范数 ≈ `1.0`。

**错误 400**：`{ "error": "texts 必须为非空数组或字符串" }`
**错误 500**：`{ "error": "<原因>" }`（如模型维度异常）

---

## 3. `POST /v1/embeddings`（OpenAI-compatible，可选）

便于直接用 openai SDK / 现成 embedding client（`baseURL` 指向本服务）。

**请求体**：`{ "input": "文本" | ["文本", ...], "model": "任意，可省略" }`

**响应 200**：
```json
{
  "object": "list",
  "data": [{ "object": "embedding", "index": 0, "embedding": [/* 512 */] }],
  "model": "BAAI/bge-small-zh-v1.5",
  "usage": { "prompt_tokens": 0, "total_tokens": 0 }
}
```

---

## 4. Node 侧最小对接示例（参考）

```ts
// 查询向量：章节意图 → 512 维向量
async function embed(text: string): Promise<number[]> {
  const res = await fetch(`${EMBEDDING_BASE_URL}/embed`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ texts: [text] }),
  });
  if (!res.ok) throw new Error(`embed failed: ${res.status}`);
  const data = await res.json();
  if (data.dim !== 512) throw new Error(`dim mismatch: ${data.dim}`);
  return data.embeddings[0]; // number[512]，可直接喂 pgvector
}

// pgvector 召回（示意）：vec 转字面量 '[...]' 或用 pgvector 适配器传数组
// ORDER BY embedding <=> $1 LIMIT $2
```

> **降级铁律**：`embed()` 抛错时，召回层应**返回空结果并记日志**，不得阻断写作主流程。

## 5. 契约稳定性承诺

| 保证项 | 说明 |
|--------|------|
| 维度恒为 512 | 换模型=破坏性变更，须升 v2 并通知 Node 侧 |
| 归一化恒为 True | Node 侧可假定向量已归一，无需再处理 |
| `/embed` 出入参不变 | 字段增量兼容；删改字段=破坏性变更 |
| 顺序保证 | `embeddings[i]` 对应 `texts[i]` |

任何破坏性变更：先在本文档标注、升版本、走三步法审核后方可发布。
