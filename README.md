## 💡 这不是又一个"AI 写小说"

> *"AI 写一段是天才，写一本是灾难。第 80 章的时候，第 3 章埋的 32 个伏笔全忘了——师父被写死两遍还不知道。"*

大多数 AI 写作工具的本质是：**输入框 + 调 API + 返回一段文字**。而我们做的，不是一个更好的提示词工程——是一个**会自己运行的世界**。

| 冰冷的工具 | 鲜活的世界 |
|------------|------------|
| 机械代笔 —— 按指令输出，无自主创造 | **自主演化** —— 角色与世界自行生长 |
| 无源之水 —— 缺乏内在动力 | **动态因果** —— 每个选择引发连锁反应 |
| 记忆缺失 —— 对话结束即遗忘 | **全息记忆** —— 伏笔、状态、时间线永不丢失 |
| 设定僵化 —— 一成不变的模板 | **无限惊喜** —— 0.1% 仙古遗珍，规则涌现的意外 |

## ✨ 功能特色

### 🎬 六道工序：世界怎么运转

```
1.观星              2.落笔             3.勘误
上下文组装          正文生成            质量审计
20+项上下文自动编排   SSE 流式实时推送    30维加权计分

     4.润色              5.记事             6.留声
     修订回炉            状态提取            金句提取
     六层策略回炉         人物·时间线·伏笔     五维评审入库
```

16 个专职 Agent 分工协作，SSE 全程可见，拒绝黑盒。**你只需要选方向——剩下的，世界自己运转。**

### 🌳 交互式剧情分支

每一章写完后，AI 在完整世界观约束下推演合理的剧情走向：

```
"前往后山禁地探查？"          → 分支A（奇遇方向）  → 影响: 修为+1 风险+3
"留在门派应对内乱？"          → 分支B（阵营方向）  → 影响: 声望+3 忠诚+2
"追随神秘老者的指引离去？"    → 分支C（探索方向）  → 影响: 气运+2 羁绊+1
```

- 10 大类 × 37 细分方向 × 主次权重 = 上千种叙事组合，告别"靠灵感写下一章"
- 每个选项附带 **影响预览**（人物数值/世界状态量化变化）
- 选定后自动 **衍生下一章计划** + 抽取伏笔 + 埋设因果线
- 分支上下文 **沿链路累积**，5 章自动收敛回主线

### 🛡️ 质量防线：写完不是结束

**52 项规则实时校验，秒级响应，零 token 消耗。** 得分不足 85 → 回炉修订，通过才能入库。

| 维度 | 审计项（部分） | 方式 |
|------|---------------|------|
| 人物连续性 | 目标一致性 · 情绪曲线 · 关系网 · 声线 · 身体状态 | LLM |
| 情节逻辑 | 动机→触发→决策→后果→兑现 五层因果链 | LLM |
| 对白张力 | 目的性 · 信息增量 · 关系推进 · 潜台词密度 | LLM |
| 章末钩子 | 禁总结句 · 停在变化拍 · 不说满 · 末句短 | LLM + 🔒 |
| 世界观硬约束 | 品阶上限 🔒· 互斥关系 🔒· 稀有度 🔒· 道则兼容 🔒· 瞬移检测 🔒 | 🔒 零 token |
| … | 共 **30 维** × 加权计分 × 85 分及格线 × 六层修订策略 | |

还有 **9 维叙事体检**——全书健康度扫描，高/中/低三级预警。质量不是碰运气，是可量化、可审计、可追溯的工程标准。

### 👤 角色·神兵·功法：三工坊

> *"好角色不是写出来的——是结构长出来的。"*

```
人物三步向导              神兵坊                      功法坊
├ 种族·修为·定位        ├ 六阶品级（凡造→神蕴）      ├ 九大本源道则
├ 性格·立场·对白风格     ├ 四类特质×方向组合           ├ 道则兼容矩阵
├ 先天禀赋(166选3-8)    ├ 五感兵器卡                 ├ 千人千面个人变种
│  ├ 3-8正向/每类≤2     ├ 强化·进化·变异·融合         ├ 配套招式自动生成
│  └ 23选1小缺陷         ├ 烙印·羁绊·魔改·克制         ├ 武学档案融合小传
└ AI判词(七绝+考语)      ├ 0.1% 仙古遗珍彩蛋           └ 确定性随机引擎（零token）
                          └ 数值平衡数学约束 🔒
```

- **功法没有品级，唯道则**——强弱全系于行功路线与道心契合度。同一门功法，道则×性格×路线×种族 = 10000+ 变种组合
- **武器不是道具，是战友**——有前尘、会堕落、能被净化。五感兵器卡 + 强化进化变异融合养成系统
- **集齐召唤**——角色+武器+功法 100% 适配时，触发涌现专属组合技：`「引天雷灌魔剑」`——因果绑定演算，1+1+1 > 3

### 🧩 叙事工程

- **伏笔台账**：伏笔不是补丁，是精确到字的结构性操作。植入为"借"，回收为"还"。超期未回收自动标红催债。
- **人物状态快照**：每章自动提取伤势、境界、心理状态，杜绝前后矛盾。
- **金句基因库**：粘贴即提取分类，按角色性格精准匹配注入。取经典之势，不取经典之文。
- **因果链**：潜伏→触发→兑现，自动埋因。
- **动态叙事引擎**（v1.4）：里程碑驱动大纲 + 分支弧管理 + 自动收敛 + 计划改写日志
- **双引擎工坊**（v1.5）：冰山台词引擎（真相→表面→行为）× 冲突引擎（欲望→阻力→代价）→ 五步组合成戏

## 🚀 快速开始

### 前置要求

- **Node.js** ≥ 20 LTS
- **pnpm** ≥ 9
- **PostgreSQL** ≥ 15（含 pgvector 扩展）
- 仙侠世界数据库（world_db）已导入

### 安装

```bash
# 1. 克隆项目
git clone <your-repo-url>
cd XianxiaForge

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env → 填入数据库连接 + LLM API Key

# 3. 一键启动（Windows）
start.bat
# 自动完成：检查环境 → 安装依赖 → 初始化DB → 启动前后端 → 打开浏览器

# 或手动启动
pnpm install
pnpm dev
```

启动后访问 **http://localhost:5173** 🎉

### 配置 LLM

支持任意 **OpenAI-compatible** 接口，不锁平台，即插即用：

| 提供商 | `.env` 配置 |
|--------|-------------|
| DeepSeek | `LLM_BASE_URL=https://api.deepseek.com` `LLM_MODEL=deepseek-chat` |
| OpenAI | `LLM_BASE_URL=https://api.openai.com/v1` `LLM_MODEL=gpt-4o` |
| 本地 Ollama | `LLM_BASE_URL=http://localhost:11434/v1` `LLM_MODEL=qwen2.5` |

主备模型自动切换：首选 LLM 宕机 → 秒切备用 → 写作者无感。
